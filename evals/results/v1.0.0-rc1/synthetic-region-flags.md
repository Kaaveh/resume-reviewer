# CV review: Senior Java Engineer for Germany and Austria (visa sponsorship needed)

**Verdict:** Borderline

**10-second verdict:** The top of page one shows "Senior Software Engineer (Java)", the most recent role "Senior Software Engineer, Banco Arvoredo" with "Java 17 and Spring Boot handling 2 million transactions a day", and a bank as employer. The technical fit is clear, so a screener keeps reading (SCR-1, SCR-2, SCR-7). What the eye also catches first: a photo, a bolded "Requires visa sponsorship (EU Blue Card)" line, star ratings in the skills, and "English: Intermediate". None of that is a hard rejection on its own, but together they plant doubt, and an undecided screener rejects (SCR-15, Single source 1).

**Target and weighting:** Senior Java Engineer, Germany and Austria, candidate abroad (Brazil) needing visa sponsorship; target from the request, not the default Android target. No job description was given, so job-specific keyword checks (ATS-1, SKL-11, RED-6) were not run. Match: JA medium (hiring manager who hires from abroad, but UK product company, not DACH or Java specific), TW medium-high (agency covering UK and Europe, including finance employers, which fits this banking background), JB medium-high (cross-border hires across EMEA), SB low (UK JavaScript and TypeScript startups). No recruiter is a high match, so no Single source rule was raised.

## Findings

### High
- **STR-3** (Consensus 3, High): the skills line uses star ratings as skill bars, "Java ★★★★★ | Spring Boot ★★★★★ | Kafka ★★★★☆ ...". Graphics like these slow skimming and add nothing. Fix: replace with a plain, grouped list (see Rewrites; also SKL-17, SKL-8 below).
- **REG-6** (Supported 2, High): the languages line says "English: Intermediate". JA and SB expect working English good enough to follow technical requirements and product direction, and one reports rejecting on it. For an English-language CV going to international teams, "Intermediate" reads as below that bar. Fix: state your real level in words a screener understands (for example professional working proficiency) only if that is true; never overstate it, because the first call will test it (RED-3). If your English really is below working level, that is the priority to work on, not the CV wording.
- **ACH-1** (Consensus 4, High): the most recent role is good, but the two earlier roles are duties with technology names only: "Built checkout and inventory APIs in Java and Spring." and "Maintained Java EE applications for insurance clients." They do not say what you personally did or what changed. Fix: one or two bullets per older role with problem, your contribution and result (see Rewrites).
- **ACH-6** (Consensus 3, High): the Banco Arvoredo bullets carry numbers ("2 million transactions a day", "latency fell by 38%"), but the Lojamar and Tecnorte bullets carry none. Fix: add real figures where you have them, as `[placeholders]` in the Rewrites show. Use only numbers you can defend.
- **ACH-4** (Consensus 3, High): no side projects, hackathons or open source are listed. JA, SB and TW read these as genuine interest, and one reports rejecting on it. Fix: if you have relevant Java or backend side projects, add one or two lines with dates and context (STR-15). If you have none, do not invent any.
- **SKL-4** (Supported 2, High): nothing shows how you use AI coding tools in your daily work. JA reports rejecting on this. TW (SKL-7, Single source 1, Low) adds that hiring managers want some hands-on AI exposure. Fix: if you use AI tools at work, add one concrete line under Banco Arvoredo on what you use them for, for example "[tool] for [task]".

### Medium
- **SKL-3** (Supported 2, Medium): "PostgreSQL", "Docker", "Kubernetes" and "AWS" appear in the skills list but in no role, so the reader cannot tell where you used them. Fix: name each one in the bullet of the role where you used it, or drop it.
- **STR-4** (Supported 2, Medium): the profile is one generic line, "Senior Java engineer with 10 years of experience in banking and e-commerce systems." It says who you are but not what you specialize in or why you fit a DACH Java role. Fix: three to four lines (STR-21, JA 3 to 4 lines) that lead with your strongest result (ACH-10) and the relocation line (see Rewrites).
- **SKL-10** (Single source 1, Medium): no testing tools are named anywhere. JA reports rejecting on this. Not raised: JA is a medium match. Fix: name the one or two testing tools you really use, and where.

### Low
- **REG-2** (Single source 1, Low): the header states "**Requires visa sponsorship (EU Blue Card)**" in bold. JB advises not stating a need for sponsorship on the CV; the sponsorship question belongs in the application form or first call. Bolding it also puts it where the eye goes first (STR-23, Single source 1, Low). Fix: remove the line and replace it with your real city and relocation plan (REG-5, REG-14). JB also wants right-to-work status to be obvious (REG-15, Single source 1, Low): the city line plus "relocating to" makes clear you are abroad without leading with the sponsorship need.
- **REG-5** (Single source 1, Low): for a candidate in Brazil there is no statement of willingness to relocate. Fix: add "Relocating to Germany or Austria" to the header or profile.
- **SKL-17** (Single source 1, Low) and **SKL-15** (Single source 1, Low): the stars rate proficiency per skill, and "Kubernetes ★★☆☆☆" and "AWS ★★☆☆☆" read as basic-level skills. Fix: drop the ratings; keep Kubernetes and AWS only if you can discuss real work with them.
- **SKL-8** (Single source 1, Low): the skills list is one flat line. Fix: group it (languages and frameworks, data and messaging, infrastructure, testing).
- **REG-3** (Supported 2, lowered from Medium to Low): the header has an email but no phone number. Lowered because both supporters (JA, SB) gave preferences and their UK context differs from a DACH target. Fix: add your real phone number with its country code (+55).
- **CHN-5** (Single source 1, Low): no LinkedIn URL in the header. Fix: add it, and keep the profile complete and consistent with the CV dates (CHN-18, Consensus 3; CHN-20, Single source 1), since recruiters use LinkedIn to check experience (CHN-21, Supported 2).
- **STR-24** (Single source 1, Low): role dates are years only, "2020 to present", "2017 to 2020". Fix: add start and end months.
- **STR-25** (Single source 1, Low): the title under the name is "Senior Software Engineer (Java)"; the target title is Senior Java Engineer. Fix: match the title of each job you apply for; your profile already calls you a "Senior Java engineer", so this is truthful.
- **STR-7** (Single source 1, Low) and **ACH-7** (Single source 1, Low): no company context or team size under each role. A DACH screener may not know Banco Arvoredo, Lojamar Commerce or Tecnorte Sistemas. Fix: two to four lines (STR-8, TW 2 to 4 lines) per recent employer: what the company does, its size, your team size `[N engineers]`.

### Judgment calls
- **REG-16** (Contested 1-1): for: TW says location filters and client ATS systems screen out applicants from abroad, and reports rejecting on it (TW-59, TW-60); against: JA says candidates blame location when skill gaps are the real cause (JA-40). Recommendation: fix the skill and presentation gaps above first, then state "Recife, Brazil. Relocating to Germany or Austria" in one line, so location is a known fact rather than a surprise.
- **STR-2** (Contested range 4): JA keeps 6 to 10 year CVs to 1 page; SB, TW and JB accept 2 or more (TW 3 to 4 only above 10 years). Recommendation: the current one page is fine and not too dense. Adding company context and better bullets may take it to 2 pages, which is also fine; do not go beyond 2.
- **SKL-5** (Contested 1-1): for: SB says cloud providers are treated as interchangeable; against: JA says they are not. Recommendation: when a job names Azure or GCP, do not claim it; present your AWS and Kubernetes work as transferable, and only at the depth you can defend.

## Rewrites

**Header**
- Before: "Senior Software Engineer (Java) | Recife, Brazil | [email]" and "**Requires visa sponsorship (EU Blue Card)**"
- After: "Senior Java Engineer | Recife, Brazil, relocating to Germany or Austria | [email] | [phone with +55 code] | [LinkedIn URL]"

**Profile**
- Before: "Senior Java engineer with 10 years of experience in banking and e-commerce systems."
- After: "Senior Java engineer with 10 years in banking, e-commerce and insurance systems. Builds payment microservices in Java 17 and Spring Boot that handle 2 million transactions a day, and led the migration of card authorization to Kafka, cutting latency by 38%. [One line on why this role or company fits you.] Relocating to Germany or Austria."

**Lojamar Commerce bullet**
- Before: "Built checkout and inventory APIs in Java and Spring."
- After: "Built the checkout and inventory APIs in Java and Spring for [what the platform sold, N orders a day]; [your own part, such as the design you owned]; [result, such as checkout errors down by [X%]]."

**Tecnorte Sistemas bullet**
- Before: "Maintained Java EE applications for insurance clients."
- After: "Maintained Java EE applications for [N] insurance clients; [one concrete result, such as [X%] fewer incidents or [feature] delivered]."

**Skills**
- Before: "Java ★★★★★ | Spring Boot ★★★★★ | Kafka ★★★★☆ | PostgreSQL ★★★★☆ | Docker ★★★☆☆ | Kubernetes ★★☆☆☆ | AWS ★★☆☆☆"
- After: "Languages and frameworks: Java 17, Java EE, Spring Boot, Spring. Data and messaging: Kafka, PostgreSQL. Infrastructure: Docker, Kubernetes, AWS. Testing: [tools you use]." (Keep Kubernetes and AWS only if you can talk about real work with them.)

**Languages**
- Before: "Portuguese: Native | English: Intermediate | German: A1"
- After: "Portuguese: native. English: [your real level, in plain words]. German: A1."

## Not covered by the evidence
- **DACH conventions.** All four recruiters work from the UK (JB also EMEA and US); none hires in Germany or Austria. So the evidence does not settle the photo question for DACH: TW's rule (REG-7, Single source 1) is against any photo, but a photo is a common convention in German-language CVs. General advice, not from the evidence: for English-language applications to international tech teams, a CV without a photo is the safer default; for German-language applications to traditional employers, a photo is common.
- **German language level.** How much a German A1 helps or hurts in Germany and Austria, and whether employers expect more, is not covered. General advice: check each job ad for a German requirement before applying.
- **Visa routes.** Whether the EU Blue Card (Germany) or the Red-White-Red Card (Austria) applies, and how employers view sponsoring them, is out of scope for the CV rules.
- **No job description.** Keyword match (ATS-1, ATS-5), share of listed skills (SKL-11) and the hard-requirement check (RED-2, RED-6) need a real job ad. Run the review again with one.
- **Beyond the CV (evidence-backed, not CV checks).** Ask for referrals (CHN-15, Consensus 3), network alongside applying (CHN-16, Supported 2), and send the hiring manager a short note on why you fit (CHN-17, Supported 2). These matter more for a candidate applying from abroad.
